# Security and account policy

This prototype must not receive platform credentials, tokens, private messages,
personal data, or production exports. Identity and hosted persistence must be
reviewed before adding user-specific dashboards or write actions.

Report suspected vulnerabilities privately to the project maintainer with a
synthetic reproduction. Human approval remains required for every external
account action.

The evaluator API requires platform-provided identity and scopes every record to
the stable per-Site user ID. Authentication does not establish team membership;
private hosting or a reviewed server-side allowlist remains required for a
restricted workspace. Do not save third-party confidential drafts.
